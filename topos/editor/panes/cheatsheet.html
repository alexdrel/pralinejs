Keyboard Shortcuts & Gestures

Tools & Views

  • B / T / L / H
    Create Box / Text / Line / Hub
  • Escape
    Cancel action or selection
  • {{shift}} Space
    Open Glyph palette
  • {{alt}} G
    Toggle ruler grid
  • {{shift}} {{mod}} V
    Switch between Editor and Viewer
  • {{shift}} {{mod}} D
    Switch between Diagram and Text Editors
  • {{mod}} Wheel / {{mod}} 0
    Zoom / Reset zoom

Selection & Editing

  • Double-Click
    Edit text or label inline
  • {{mod}} Click
    Select container and toggle its contents
  • {{shift}} Click
    Toggle selection of element
  • {{mod}} A / {{mod}} {{alt}} A
    Document / all map elements
  • Drag (+ {{shift}} / {{shift}} {{alt}})
    Replace / add / subtract marquee
  • ←→↑↓
    Nudge selection by 1 cell
  • {{shift}} ←→↑↓
    Resize selected boxes
  • Delete/Bksp
    Delete selected elements

Creation Gestures

  • Double-Click
    Create Text on empty space
  • {{mod}} Drag
    Draw Box / Line / Hub
  • {{alt}} Click
    Create Hub
  • {{alt}} Drag
    Draw Line

Format & Reshape

  • Space
    Open Create / formatting controls
  • {{alt}} A / R / F
    Unicode / corners / reverse arrow
  • {{alt}} S
    Cycle box stack
  • {{alt}} {{shift}} S
    Cycle stack layout
  • {{alt}} B
    Enbox selection
  • {{alt}} I
    Toggle Note / Inline
  • {{alt}} {{shift}} I
    Cycle Inline brackets

Clipboard & History

  • {{mod}} C / X
    Copy / Cut selection
  • {{mod}} V
    Paste at last clicked position
  • {{mod}} D
    Duplicate selection down
  • {{mod}} ]
    Duplicate selection right
  • {{shift}} {{mod}} Arrow
    Duplicate selection in a direction
  • {{mod}} Z / Y
    Undo / Redo
  • {{shift}} {{mod}} Enter
    Rebuild diagram
